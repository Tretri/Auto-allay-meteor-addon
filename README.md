Allay Addon for Meteor Client (Fabric 1.21.11)

A small addon for allay dupe. It adds three modules for automatization.

Allay Breeder
Feeds amethyst shards to allays. It remembers when each allay was last fed and tries again once the cooldown is over. If an allay keeps the shard in its hand, the module takes it back. There is also a mode that skips the cooldown timer and just keeps trying (I'd recommend this mode).

Allay Kill Aura
Attacks only allays that are holding a shulker box. It picks one target and sticks with it until that allay dies or goes away, so hits are not spread around. It can switch to a hotbar item with Looting.

Allay Auto Giver
Gives shulker boxes to allays with empty hands. If an allay is holding something else, it takes that item back and hands over a shulker instead. You can pick a shulker color or allow any.

Notes: shulkers and shards need to be in your hotbar. The addon was made for laggy servers too, so it waits for the server to answer before acting again. Not fully tested everywhere, so bugs are possible.
